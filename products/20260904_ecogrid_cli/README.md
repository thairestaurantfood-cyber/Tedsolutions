# EcoGrid CLI

Track and optimize electricity consumption based on real-time carbon intensity across global grids.

## Problem
Indie hackers and developers struggle to reduce electricity costs and environmental impact due to lack of accessible real-time carbon intensity data for global grids.

## Solution  
CLI tool that fetches real-time carbon intensity data for 38 global grids, provides optimization suggestions for electricity usage, and tracks personal carbon footprint from electricity consumption.

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
