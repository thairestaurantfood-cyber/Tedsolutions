# AgentOS



## Problem
Local AI agents have no coordination layer - each runs in isolation with no shared memory, no task routing, no skill registry

## Solution  
A lightweight local-first agent operating system: process registry, task queue, shared memory bus, skill loader, and status dashboard in one CLI

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
