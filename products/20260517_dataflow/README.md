# DataFlow



## Problem
Everyone struggles with messy data - CSV files with inconsistent formatting, JSON logs that need parsing, or text reports that require extraction. Non-technical people waste hours manually cleaning data, while developers reinvent the same parsing logic over and over.

## Solution  
A universal CLI tool that intelligently detects, cleans, transforms, and exports data between formats (CSV, JSON, XML, TXT, SQL) with zero configuration. Uses heuristics to guess structure, provides interactive preview, and outputs clean, ready-to-use data.

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
