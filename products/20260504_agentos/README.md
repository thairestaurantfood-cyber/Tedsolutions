# AgentOS

Local-first CLI to orchestrate AI agents with SQLite, JSON, and subprocesses

## Problem
Indie hackers and small businesses waste time stitching together multiple AI tools, scripts, and APIs manually, leading to broken workflows and vendor lock-in.

## Solution  
AgentOS provides a lightweight, offline-first kernel to define, run, and monitor AI agents entirely in Python stdlib, with SQLite persistence and subprocess-based tooling.

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
