# ContextCraft

Clean up messy SRT files in seconds with AI-free Python CLI

## Problem
Indie hackers and small businesses waste hours manually fixing garbled SRT files from auto-transcription tools, leading to poor video engagement and customer complaints.

## Solution  
A Python CLI that parses, validates, and auto-cleans SRT files by removing duplicates, fixing timestamps, and standardizing formatting—no AI, no internet required.

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
