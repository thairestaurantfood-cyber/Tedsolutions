# Invoice Chaser CLI

A minimalist Python CLI to track invoices and chase overdue payments for freelancers.

## Problem
Freelancers and small businesses often lose valuable time manually tracking invoice due dates and sending follow-up reminders, leading to delayed payments and cash flow issues.

## Solution  
Invoice Chaser provides a simple command-line interface to add invoices, mark them as paid, list overdue invoices, and generate templated follow-up messages, ensuring timely payment reminders without complex software.

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
