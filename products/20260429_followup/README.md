# FollowUp

Never lose a client lead — track every conversation and follow-up

## Problem
Freelancers forget to follow up with leads and lose business

## Solution  
CLI tool to log client conversations, set follow-up reminders, see who to contact today

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
