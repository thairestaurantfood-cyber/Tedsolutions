# SQLiteStudio

Instantly browse and query SQLite databases with formatted table output

## Problem
Developers constantly need to inspect SQLite databases during development. No good CLI viewer exists that shows formatted tables with real data.

## Solution  
A CLI tool that inspects SQLite databases and displays schema information in formatted table output, with --demo mode showing realistic sample data

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
