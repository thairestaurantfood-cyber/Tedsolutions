# Sandbox CLI

Spin up disposable dev sandboxes with live preview URLs in seconds

## Problem
Developers waste hours configuring environments and waiting for deployments just to test small changes

## Solution  
Run `sandbox add myapp` to create a Docker container with a live preview URL instantly, no cloud accounts or complex setups needed

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
