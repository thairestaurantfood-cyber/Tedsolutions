# Voker

Turn AI agent logs into actionable analytics without the hassle.

## Problem
Indie hackers and small businesses waste hours debugging AI agents by manually parsing unstructured logs across multiple files.

## Solution  
CLI tool that ingests agent logs, stores them in SQLite, and generates concise reports on performance, errors, and usage patterns in seconds.

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
