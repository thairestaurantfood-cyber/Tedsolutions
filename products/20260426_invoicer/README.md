# Invoicer
Automates invoice processing for small businesses using AI

python3 main.py --help
python3 main.py --demo

## Problem
Manual invoice processing is time-consuming and prone to errors, with 61% of businesses spending over 10 hours per week on accounts payable tasks

## Features
1. Invoice scanning and OCR
2. Automatic data extraction
3. Integration with QuickBooks Online
4. User dashboard for invoice management
5. Basic reporting and analytics
