# LOCAL_MARKET_VALIDATOR

Validate local market demand for Phuket businesses by scraping Facebook groups, Google Maps, and local directories

## Problem
Phuket-based entrepreneurs and small businesses struggle to validate local market demand before investing time and money.

## Solution  
CLI tool that scrapes Facebook groups, Google Maps, and local directories to provide validated local business opportunities with real data.

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
