# InvoiceChaser

Automate overdue invoice follow-ups for freelancers with zero manual work.

## Problem
Freelancers waste hours chasing late payments manually, losing revenue and productivity.

## Solution  
CLI tool that tracks invoices, sends automated polite reminders, and generates reports—all offline-first with SQLite.

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
