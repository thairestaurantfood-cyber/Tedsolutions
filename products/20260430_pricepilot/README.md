# PricePilot

Automates competitor price tracking across multiple sites

## Problem
Manual price tracking is time-consuming and prone to errors, with 70% of businesses spending over 5 hours a week on competitor research

## Solution  
PricePilot automates price tracking, alerts users to price changes, and provides historical price data for analysis

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
