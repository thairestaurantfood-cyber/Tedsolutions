# Freelancer Pro Suite

All-in-one CLI toolkit — CRM, invoices, tax, proposals in one command

## Problem
Freelancers waste time switching between CRM, invoicing, tax tools, and proposal generators, losing track of clients and payments.

## Solution  
A single CLI tool that unifies client management, invoicing, tax estimation, and proposal generation with minimal friction.

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
