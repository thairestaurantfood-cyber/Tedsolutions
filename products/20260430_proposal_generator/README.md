# Proposal Generator

Generate professional text proposals with ease

## Problem
Freelancers and small agencies struggle to create high-quality proposals quickly.

## Solution  
Proposal Generator automates the proposal creation process, saving time and reducing errors. It provides a simple interface for generating professional-looking proposals based on predefined templates.

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```
