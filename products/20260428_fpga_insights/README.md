# FPGA Insights

Unlocking business intelligence with FPGA-accelerated data analysis

## Problem
Businesses struggle to analyze large datasets quickly and efficiently, with 60% of companies citing data analysis as a major challenge

## Solution  
FPGA Insights uses an AMD Alveo V80 FPGA PCI card to accelerate data analysis, providing fast and efficient insights for businesses

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```
