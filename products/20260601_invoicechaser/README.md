# InvoiceChaser

Automate overdue invoice reminders for freelancers and small businesses.

## Problem
Freelancers and small businesses waste hours manually chasing late payments, hurting cash flow and productivity.

## Solution  
CLI tool that tracks invoices, sends automated polite reminders, and generates reports—all offline with optional email/SMS alerts.

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
