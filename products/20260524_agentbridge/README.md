# AgentBridge

Turn any CLI tool into an MCP server in 5 lines

## Problem
Developers have CLI tools that AI agents cannot use because they lack MCP interfaces

## Solution  
A CLI wrapper that auto-generates an MCP server from any Python CLI tool

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
