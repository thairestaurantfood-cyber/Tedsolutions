# SkillSwarm

Crowdsourced AI agent skills marketplace for indie devs and small teams

## Problem
AI agents lack a central place to discover, share, and monetize reusable skills, forcing developers to rebuild common functionality from scratch

## Solution  
1) CLI tool to publish AI agent skills as JSON files 2) Marketplace to browse/search skills 3) One-command install for any skill 4) Ratings/reviews to ensure quality 5) Monthly subscription for premium features

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
