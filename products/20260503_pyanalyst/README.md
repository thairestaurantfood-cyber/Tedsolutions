# PyAnalyst

Turn CSV files into Python notebooks with local AI insights

## Problem
Freelancers and small agencies waste hours manually analyzing CSV data in spreadsheets or Jupyter notebooks

## Solution  
CLI tool that reads CSV, generates Python notebooks with automated insights, and saves results locally

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
