# CliTrack

Track business metrics from your terminal with zero setup

## Problem
Small businesses waste hours weekly exporting data to spreadsheets

## Solution  
CLI tool that ingests CSV/JSON, stores in SQLite, and generates instant reports with alerts

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
