# SchemaSpy

Turn any database into interactive docs in seconds.

## Problem
Developers waste hours manually documenting database schemas or using complex tools that require setup and internet access.

## Solution  
A lightweight CLI tool that scans your local database (SQLite, MySQL, PostgreSQL via CLI tools) and generates a clean, searchable HTML/Markdown documentation file instantly—no internet, no config, no bloat.

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
