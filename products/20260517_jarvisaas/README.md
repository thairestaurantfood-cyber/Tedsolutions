# JARVISaaS



## Problem
Indie hackers want an AI that builds products overnight while they sleep but can't set up the infrastructure. They need a hosted version of JARVIS that runs autonomously.

## Solution  
CLI + web dashboard where users connect Telegram, set their niche, and JARVIS builds products autonomously overnight. Users get a summary each morning.

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```
