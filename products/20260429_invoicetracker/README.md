# InvoiceTracker

Track invoices, get paid faster — CLI tool for freelancers

## Problem
Freelancers forget to follow up on late invoices and lose money

## Solution  
CLI tool to create invoices, track payment status, send reminders via Telegram

## Usage
```bash
python3 main.py --help
python3 main.py --demo
```

## Tech Stack
os, sys, json, csv, sqlite3, argparse, datetime, pathlib, subprocess, urllib.request, re, time
